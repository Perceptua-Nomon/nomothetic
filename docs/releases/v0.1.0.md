# nomothetic v0.1.0

**Released:** 2026-03-11
**Type:** Initial release

---

## Summary

First release of nomothetic, the Python server package for the nomon fleet.
Covers all completed phases: camera module, MJPEG streaming, HTTPS REST API,
MQTT telemetry, HAT IPC client, and vehicle convenience endpoints.

---

## Features

### Camera (`nomothetic.camera`)
- Still image capture and H264/MJPEG video recording via `picamera2`
- JPEG frame generator for MJPEG streaming
- Path traversal–safe filename validation

### MJPEG Stream Server (`nomothetic.streaming`)
- Flask-based stream server with HTML viewer
- `GET /stream` — multipart/x-mixed-replace MJPEG feed
- Background thread mode (`start_background()`)

### HTTPS REST API (`nomothetic.api`)
- FastAPI + uvicorn with auto-generated self-signed TLS certificates
- Camera endpoints: capture, record start/stop, stream info, status
- HAT endpoints: battery voltage, servo angle, MCU reset, servo/MCU status
- Motor endpoints: `POST /api/hat/motor`, `POST /api/hat/motor/stop`, `GET /api/hat/motor/status`
- Vehicle endpoints: `POST /api/drive`, `POST /api/steer`, `POST /api/camera/pan`,
  `POST /api/camera/tilt`, `GET /api/sensor/grayscale`
- OpenAPI docs at `/docs` and `/redoc`
- CORS middleware for mobile clients
- 503 returned when HAT daemon is unavailable

### MQTT Telemetry (`nomothetic.telemetry`)
- Background daemon thread publishing structured JSON to configurable MQTT broker
- Device ID from env var, Pi CPU serial, or hostname
- Exponential back-off reconnect (1 s → 60 s cap)

### HAT IPC Client (`nomothetic.hat`)
- `HatClient` — typed Python façade over the nomopractic Unix socket IPC
- Methods: `health`, `get_battery_voltage`, `set_servo_angle`, `set_servo_pulse_us`,
  `reset_mcu`, `get_servo_status`, `get_mcu_status`, `set_motor_speed`,
  `stop_all_motors`, `get_motor_status`, `drive`, `steer`, `pan_camera`,
  `tilt_camera`, `read_grayscale`
- All methods validated and tested with mock socket server (no Pi required)

### Deployment
- `scripts/deploy.sh` — SSH deploy to Pi with rollback on failure
- `scripts/start.sh` / `scripts/stop.sh` — background process management
- `Makefile` targets: `install-pi`, `check`, `deploy`, `start-api`, `stop`, etc.
